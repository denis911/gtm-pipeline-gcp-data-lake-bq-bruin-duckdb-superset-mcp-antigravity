# GTM Intelligence Dashboards

This directory contains the serialized Apache Superset / Preset.io dashboards for this project.

## How to use
As part of our "Everything-as-Code" philosophy, we version our dashboards here.

### Exporting (Manual)
1. In Preset/Superset, go to **Dashboards**.
2. Select the dashboard and click **Export**.
3. Move the downloaded ZIP/YAML file to this directory.

### Importing (Manual)
1. Click **Import Dashboard** in the Superset UI.
2. Upload the file from this directory.
3. Re-link the database connection if prompted.
